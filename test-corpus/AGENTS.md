# Test corpus rules

Root `AGENTS.md` also applies.

- Keep fixtures synthetic, small, deterministic, and focused on parser/format behavior.
- Do not add scraped/copied literary text merely because an author is old.
- If a real public-domain fixture is deliberately added, document the exact text version, source, and rights status.
- Never add private user questions, real saved encounters, production corpus outputs, or model/index artifacts.
- Keep [`IMPLEMENTATION.md`](IMPLEMENTATION.md) aligned when fixture layout or smoke-build behavior changes.
